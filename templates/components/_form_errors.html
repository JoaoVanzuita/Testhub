{% comment %} Focusable error summary (design system §5.2, "Focusable Error Summary"). Renders once per form, at the top, only when there is something to fix. It collects every error the form knows about — field errors, ``non_field_errors`` and, when a formset is passed, its ``non_form_errors`` and per-step field errors — and links each one to the control it belongs to. ``app.js`` moves focus to ``#form-errors`` on load and focuses the linked control when a summary link is activated, so the summary is reachable and the focus lands on the offending field. The summary is the single assertive announcement for the page: the inline ``.field__error`` messages stay visible but are not separate live regions, which avoids announcing the same error several times to assistive technology. Context: form — required, the bound form. formset — optional, a bound inline formset (e.g. the ordered steps).
